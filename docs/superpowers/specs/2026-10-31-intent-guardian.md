# Canvas Atlas intent-aware safety guardian

User-authorized implementation: the attached “SUPERPOWER: CANVAS ATLAS INTENT-AWARE SAFETY GUARDIAN” specification and explicit “do”. This supersedes the earlier permissive reproduction-education prompt. Existing visuals, local lesson storage, official ChatGPT authorization, Gemini/Groq routing and voices remain supported.

The selected teaching provider performs contextual classification, with backend schema validation and a versioned policy making the final ALLOW/BLOCK/REVIEW decision. There is no local automatic ALLOW or frontend-only authorization. Narrow deterministic blocks supplement semantic classification. The original request and raw relevant conversation are retained; blocked requests never create sessions, roadmaps or generation tools, and are never silently reframed.

Default student policy declines sexual/explicit content, pornographic recommendations, human reproduction lessons and detailed sex education, operational violence, weapons/drugs/malware/credential theft, self-harm instructions and safety bypass. Harmless academic biology, science, programming and history remain eligible. Uncertain/unavailable classification fails closed. Urgent personal-health concerns receive fixed non-graphic help-seeking copy. Alternatives only prefill a new draft.

Backend capabilities bind exact task, subject generation, provider identity and policy. Cancellation/provider changes invalidate work. Output is buffered and checked before tools, persistence, playback or delivery. Imports, notes, saved lessons, replay, annotation changes, narration and simulation admission use the same gate. Numeric frames and exact approved narration prefixes derive from approved parents without an inference call per animation tick.

Exact artifact approvals use HMAC receipts with an OS-protected local key. Approved saved work can reopen offline; unknown or changed legacy content requires an online review. No plaintext secret fallback. Compiled static app copy alone may use trusted registration. PDF preview/export consume verified bytes, not a path that may change while a dialog is open.

Classifier calls consume the selected account's quota and add latency. Inputs and outputs go to that provider. Local diagnostics are bounded metadata only, with keyed digests and no raw prompts/keys/reasoning. Policy confidence is a model estimate, not a calibrated probability. Large content is bounded and chunked without silently dropping original passages; over-limit content is refused. Semantic accuracy, cumulative intent across very long chunks, OCR/image understanding and multilingual robustness still require ongoing evaluations; automated tests do not establish complete safety.

Acceptance: strict blocked/uncertain requests stop before generation; safe requests flow through real backend gates; stale/forged capabilities fail; unavailable classification fails closed; signed offline restoration works; changed PDF/documents fail; full raw history is checked for notes; failed simulation admission preserves healthy runs; native and packaged tests exercise the actual app with synthetic HTTP fixtures, without real keys.
